# Поточна мережева конфігурація Proxmox

## Мета

Описати інтерфейси, маршрутизацію, NAT і мережеві обмеження вузла Proxmox VE 8.

## Архітектура

`nic0` підключений через MikroTik до `192.168.100.0/24` і входить до `vmbr0`. USB Wi-Fi `wlxe4fac44cf127` описаний як зовнішній uplink. VM підключені до `vmbr0` через інтерфейси `tap`, `fwbr` і `fwln`.

## Передумови

- консольний доступ до Proxmox;
- резервна копія `/etc/network/interfaces`;
- зафіксовані чинні правила firewall;
- вікно робіт для змін мережі.

## Конфігурація

| Інтерфейс | Роль | Адреса |
|---|---|---|
| `nic0` | Фізичний LAN-адаптер | У складі `vmbr0` |
| `nic1` | Фізичний адаптер | Роль не підтверджено |
| `vmbr0` | Міст Proxmox і VM | `192.168.100.196/24` |
| `wlxe4fac44cf127` | USB Wi-Fi uplink | DHCP у `10.192.0.0/21` |

Зафіксований стан маршрутів:

```text
default via 10.192.7.254 dev wlxe4fac44cf127
10.192.0.0/21 dev wlxe4fac44cf127 proto kernel scope link src 10.192.1.253
192.168.100.0/24 dev vmbr0 proto kernel scope link src 192.168.100.196
```

IP forwarding увімкнено через `/etc/sysctl.d/99-ipforward.conf`:

```text
net.ipv4.ip_forward=1
```

NAT для внутрішньої мережі:

```bash
iptables -t nat -A POSTROUTING -s 192.168.100.0/24 -o wlxe4fac44cf127 -j MASQUERADE
```

Правила зберігаються через `iptables-persistent`. Вхідні SSH, Proxmox GUI та ICMP echo request з Wi-Fi інтерфейсу описані як заблоковані.

MAC-адресу Wi-Fi задано вручну, hostname вузла змінено, IPv6 на Wi-Fi вимкнено через `/etc/sysctl.d/99-disable-ipv6-wifi.conf`. Значення Wi-Fi облікових даних у документації не зберігаються.

## Покрокове налаштування

1. Створити резервні копії мережевих файлів і правил.
2. Перевірити відповідність назв інтерфейсів фактичному вузлу.
3. Налаштувати `vmbr0` зі статичною адресою.
4. Налаштувати Wi-Fi через окремий захищений файл `wpa_supplicant`.
5. Увімкнути IPv4 forwarding.
6. Додати NAT і мінімальні правила forwarding.
7. Обмежити керування з Wi-Fi.
8. Зберегти правила та перевірити їх після перезавантаження.

## Перевірка

```bash
ip address
ip route
sysctl net.ipv4.ip_forward
iptables -S
iptables -t nat -S
```

Перевірити доступ VM назовні, відсутність доступу до `22/tcp` і `8006/tcp` з Wi-Fi та локальний доступ до Proxmox.

## Troubleshooting

| Симптом | Можлива причина | Рішення |
|---|---|---|
| VM не мають інтернету | Forwarding або NAT не працює | Перевірити sysctl, маршрути й лічильники iptables |
| Proxmox недоступний після змін | Помилка bridge або адреси | Використати локальну консоль і відновити конфігурацію |
| Правила зникли після reboot | Не оновлено persistent rules | Повторно зберегти перевірений набір правил |
| Wi-Fi не підключається | Змінилася мережа або ім’я адаптера | Перевірити `wpa_supplicant` і `ip link` |
