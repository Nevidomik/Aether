# Astra

**Astra** — централізований репозиторій інфраструктури університетсського навчального кіберполігону.

Репозиторій містить:
- архітектуру та технічну документацію;
- конфігурації мережевого та серверного обладнання;
- процедури розгортання, резервного копіювання та відновлення.

Інфраструктура будується на базі **Proxmox VE** та мережевого обладнання **MikroTik** і призначена для розгортання ізольованих навчальних середовищ, проведення лабораторних робіт і практичних занять з кібербезпеки.

## Структура репозиторію

| Каталог | Призначення |
| --- | --- |
| [`docs/`](docs/) | Архітектура, інструкції, експлуатація та troubleshooting |
| `configs/` | Санітизовані конфігурації обладнання й операційних систем |
| `deployments/` | Docker Compose та інші конфігурації розгортання сервісів |
| `automation/` | Ansible, службові скрипти й автоматизація |
| `inventory/` | Перелік обладнання, мереж, вузлів і сервісів |


## Основні принципи

- Документація та конфігурації повинні відповідати фактичному стану системи.
- Зміни інфраструктури фіксуються разом з відповідними змінами документації.
- Конфігурації повинні дозволяти відновити інфраструктуру з нуля.
- Паролі, токени, приватні ключі та сертифікати не зберігаються в Git.
- Для секретів використовуються лише шаблони `*.example` або посилання на
  зовнішнє сховище секретів.
