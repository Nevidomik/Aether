# AGENTS.md

## Мета репозиторію

Цей репозиторій містить повну технічну документацію домашнього кіберполігону, побудованого на базі Proxmox VE, MikroTik, Ubuntu Server, Docker та допоміжних сервісів.

Документація повинна бути достатньою для повного відновлення інфраструктури з нуля без використання сторонніх джерел.

---

# Загальні принципи

Вся документація ведеться українською мовою.

Markdown є основним форматом документації.

Будь-які зміни інфраструктури повинні супроводжуватись оновленням документації.

Документація повинна відповідати фактичному стану системи.

---

# Стиль документації

Писати технічно.

Не використовувати художній стиль.

---

# Код

Усі команди оформлювати окремими блоками.

Всі команди повинні бути готовими до копіювання.

Приклад:

```bash
systemctl restart pveproxy
```

---

# Назви документів

Використовувати kebab-case.

Приклади:

```
mikrotik-base-config.md
tailscale-installation.md
proxmox-network.md
```

---

# Структура документації

Створювати документи за цілісними темами за потреби з посиланнями на інші документи.

---

# Робота з мережею

Описувати:

- фізичну схему
- адресний простір
- маршрути
- NAT
- Firewall
- VPN
- DHCP
- DNS

---

---

# Troubleshooting

Будь-яка проблема після успішного вирішення повинна отримати окремий документ.

Формат наприклад:

- Симптоми
- Причина
- Діагностика
- Рішення
- Перевірка
- Профілактика

---

# README

README не повинен дублювати документацію.

README лише пояснює:

- що це за проект;
- з чого він складається;
- де шукати потрібну інформацію.

---

# Безпека

Не зберігати:

- паролі;
- токени;
- ключі;
- приватні сертифікати.

Допускаються:

- приклади;
- шаблони;
- *.example.
