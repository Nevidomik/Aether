# Технічна документація

Цей каталог містить документацію архітектури, конфігурації, експлуатації та відновлення університетського кіберполігону.

Усі технічні документи створюйте за [обов'язковим шаблоном](templates/technical-document-template.md). Одна тема повинна відповідати одному Markdown-файлу.
