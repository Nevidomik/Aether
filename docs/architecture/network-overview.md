# Огляд мережевої архітектури

## Мета

Зафіксувати поточну структуру мережі університетського кіберполігону та межі підтвердженої конфігурації.

## Архітектура

Основу полігону складають:

- сервер з Proxmox VE 8;
- 24-портовий маршрутизатор-комутатор MikroTik;
- TP-Link WR841N v11 у режимі WDS Bridge;
- USB Wi-Fi адаптер сервера;
- внутрішня мережа `192.168.100.0/24`;
- дві Ubuntu VM;
- віддалений доступ через Tailscale.

Описано два варіанти зовнішнього підключення:

1. Proxmox напряму виходить у мережу `Nuwm` через USB Wi-Fi та виконує NAT для VM.
2. TP-Link підключається до `Nuwm` як WDS-міст і передає з’єднання на WAN MikroTik, який виконує маршрутизацію та NAT.

Активний основний варіант необхідно підтвердити під час інвентаризації.

## Передумови

- фізичний доступ до обладнання;
- адміністративний доступ до Proxmox, MikroTik і TP-Link;
- актуальні експорти конфігурацій без секретів;
- схема підключення патч-панелей.

## Конфігурація

| Компонент | Роль | Відомі параметри |
|---|---|---|
| Proxmox VE 8 | Гіпервізор, міст і можливий NAT-шлюз | `192.168.100.196/24` |
| MikroTik | L3-шлюз і 24-портовий комутатор | `192.168.100.1/24` |
| TP-Link WR841N v11 | WDS-міст | `192.168.0.1/24` |
| USB Wi-Fi | Альтернативний uplink Proxmox | DHCP, `10.192.0.0/21` |
| Tailscale | Віддалений доступ | маршрут `192.168.100.0/24` |

## Покрокове налаштування

1. Підтвердити активний шлях до інтернету.
2. Зняти актуальні конфігурації всіх мережевих компонентів.
3. Звірити адреси, порти, маршрути, NAT і правила firewall.
4. Доповнити фізичну схему підключеннями патч-панелей та аудиторних розеток.

## Перевірка

- Proxmox доступний з адміністративної мережі;
- VM обмінюються трафіком у внутрішній мережі;
- вихід VM в інтернет проходить лише через визначений шлюз;
- керування не доступне безпосередньо з зовнішньої Wi-Fi мережі;
- маршрут Tailscale працює для дозволених адміністраторів.

## Troubleshooting

| Симптом | Можлива причина | Рішення |
|---|---|---|
| Є два маршрути за замовчуванням | Одночасно активні два uplink | Визначити основний uplink і метрики маршрутів |
| VM не мають інтернету | Неправильний шлюз або NAT | Перевірити маршрут VM, forwarding і лічильники NAT |
| Немає доступу до керування | Невірна адресація або firewall | Перевірити локальний маршрут і правила input |
