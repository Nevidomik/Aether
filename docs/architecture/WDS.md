# TP-Link WR841N v11 як WDS Bridge

## Мета

Описати TP-Link як прозорий бездротовий міст між мережею `Nuwm` і WAN MikroTik.

## Архітектура
  
TP-Link підключається до `Nuwm` через WDS. Його LAN-порт з’єднаний з `ether1-WAN` MikroTik. WAN-порт TP-Link не використовується.

## Передумови
  
- TP-Link WR841N v11 підтримує налаштований WDS;
- відомі параметри Wi-Fi, які не зберігаються в репозиторії;
- локальний доступ до панелі TP-Link;
- резервна копія конфігурації, якщо її підтримує прошивка.

## Конфігурація

| Параметр            | Значення                            |
| ------------------- | ----------------------------------- |
| Режим               | WDS Bridge                          |
|                     |                                     |
| IP керування        | `192.168.0.1/24`                    |
| DHCP server         | Вимкнений                           |
| Бездротова мережа   | `Nuwm`                              |
| Фізичне підключення | LAN TP-Link → `ether1-WAN` MikroTik |
| WAN-порт TP-Link    | Не використовується                 |

## Покрокове налаштування

1. Встановити LAN IP `192.168.0.1/24`.
2. Вимкнути DHCP-сервер.
3. Увімкнути WDS Bridging.
4. Вибрати `Nuwm` і ввести пароль без його фіксації в документації.
5. Зберегти конфігурацію.
6. Підключити LAN-порт TP-Link до `ether1-WAN` MikroTik.

## Перевірка

- TP-Link має стабільний WDS-зв’язок;
- MikroTik отримує DHCP-адресу з `10.192.0.0/21`;
- `192.168.0.1` доступна через службову адресу MikroTik;
- DHCP TP-Link не з’являється у внутрішній мережі.
  
## Troubleshooting

| Симптом                   | Можлива причина                              | Рішення                                 |
| ------------------------- | -------------------------------------------- | --------------------------------------- |
| WDS не підключається      | Неправильні параметри Wi-Fi або несумісність | Перевірити SSID, захист і підтримку WDS |
| MikroTik не отримує DHCP  | WDS не передає L2 або кабель несправний      | Перевірити link і DHCP client           |
| Панель TP-Link недоступна | Немає маршруту/src-nat до `192.168.0.1`      | Перевірити службову адресу MikroTik     |
