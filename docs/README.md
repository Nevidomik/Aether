# Документація Astra

Цей каталог містить документацію архітектури, конфігурації, експлуатації та відновлення університетського кіберполігону.

Документація описує (чи повинна описувати):

- архітектуру та поточний стан інфраструктури;
- фізичну й логічну мережу;
- обладнання та його призначення;
- порядок налаштування, перевірки й відновлення;
- експлуатаційні та навчальні сценарії;
- відомі проблеми та способи їх усунення.

## Поточні документи

- [Мережа](network.md) — обладнання, фізична й логічна топологія,
  адресація, підключення, маршрутизація та віддалений доступ.

## Матеріали

Схеми, зображення та інші графічні матеріали зберігаються в `assets/`.

## Організація документації

Пов’язану інформацію слід зберігати в одному цілісному документі.
Новий файл або тематичний каталог створюється лише тоді, коли наявний
документ стає складно переглядати й підтримувати або коли з’являється
кілька самостійних документів одного напряму.

Документація повинна відрізняти:

- підтверджений фактичний стан;
- заплановані зміни;
- параметри, які ще потребують перевірки.

Паролі, токени, приватні ключі та інші секрети в документації не
зберігаються.

За потреби один з варіантів розширення структури документації:

```text
docs/
├── architecture/       # Архітектура та мережа
├── infrastructure/     # Обладнання, MikroTik, Proxmox
├── services/           # Розгорнуті сервіси
├── labs/               # Навчальні середовища та сценарії
├── operations/         # Експлуатація, backup та troubleshooting
├── security/           # Заходи безпеки
└── assets/             # Схеми, зображення та інші матеріали
```
